# page-gen-test — песочница для генерации страниц сайта

Тестовый проект: сюда генерируются пробные страницы, чтобы посмотреть результат
до переноса в боевой проект.

## Структура

| Путь | Что это |
|---|---|
| `index.html` | Текущая тестовая страница |
| `styles.css` | Стили страницы |
| `assets/img` | Картинки (генерация через /imagegen) |
| `drafts` | Прошлые варианты, чтобы сравнивать |

## Запуск

`serve.cmd` — поднимает локальный сервер на портативном PHP:
http://127.0.0.1:8090
