# VX-11 Nocturne

**Открыть сайт:** https://quroroyr.github.io/sobaka/

Интерактивная витрина робопса VX-11 — автономного четвероногого прототипа. Робота можно
крутить, разбирать на детали, двигать ему голову, лапы и хвост и сохранять свои позы.

## Что умеет

- **Разборка на узлы**: голова с оптикой, передняя и задняя часть корпуса, кинетический
  хребет, лапы, хвост-балансир. Каждую деталь можно вытащить и рассмотреть.
- **Режимы**: Inspect (осмотр), Assembly (сборка), Exploded view (разнесённый вид).
- **Ручное управление**: поворот головы, морда, хвост, поза корпуса.
- **Позы**: сохранить свою позу и вернуться к ней; сброс робота к исходной.
- **Панель телеметрии**: статус систем, обороты ядра, нагрузка сервоприводов, температура.
- 6 глав с плавными переходами.

## Управление

| Действие | Как |
|---|---|
| Двигать деталь | тянуть деталь левой кнопкой |
| Вращать деталь | тянуть правой кнопкой или с Shift |
| Повернуть камеру | тянуть по пустому месту |
| Приблизить | колесо (в режиме Inspect — с Shift) |
| Сфокусироваться на детали | двойной клик, выйти — Esc |

## Как сделано

- Одна страница без сборки и без установки: вся логика в `index.html`.
- **Three.js 0.170** подключается с CDN jsDelivr через import map.
- Весь робот построен кодом, 3D-моделей нет: панели с настоящей толщиной, кромками
  и швами (лофт по суперэллипсу), иерархия суставов для лап и хвоста.
- Материалы на `MeshPhysicalMaterial` / `MeshStandardMaterial` с доработкой шейдера:
  разброс шероховатости, потёртости, мелкие царапины. Светящиеся элементы — через bloom.
- Шрифты Syncopate и JetBrains Mono (Google Fonts).

## Запуск у себя

Скачайте репозиторий (Code → Download ZIP) и откройте `index.html` в браузере.
Если браузер не пускает страницу из файла, поднимите в папке любой локальный сервер, например:

```
npx serve .
```

Нужен интернет (Three.js и шрифты грузятся с CDN) и браузер с WebGL.
